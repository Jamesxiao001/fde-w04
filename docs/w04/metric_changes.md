# 指标修订

## 本次修订的指标 ID 清单

共修订 5 项，指标 ID 均不变；只改 `metrics.yml` 的 description 和 `catalog.json` 的 sources、constraints，SQL 与度量表达式不变：

1. `new_member_count`（注册会员数）
2. `first_buyer_count`（观测期首购会员数）
3. `first_order_sales_cents`（观测期首单净销售额）
4. `first_order_count`（观测期首单数）
5. `repeat_order_count`（观测期后续购买订单数）

其余 33 项核对后**无需修改**：27 项订单、金额、比率与月内复购指标——订单状态已在清洗规则中映射为 paid／cancelled、金额转为整数分，定义与 W4 业务模型无冲突；6 项月末付费会员指标——小林复核月报只计悦享年卡、家庭季卡（MSG-05493），`order_facts.sql` 第 28 行 `card_type IN ('悦享年卡', '家庭季卡')` 与之一致（见 model_changes.md M9）。

## 逐项修订前与修订后定义

### 1. `new_member_count`

- 修订前 description：按注册日期统计新注册 CRM 账户数；可按归属门店和会员等级分组，不等于自然人数。
- 修订后 description：按入会日期统计新注册 CRM 账户数；系统导入账户按原入会日期计，不按新 CRM 建档时间；可按归属门店和会员等级分组，不等于自然人数。
- catalog constraints 新增：注册日期取入会日期，不用新 CRM 建档时间；系统导入账户的建档时间晚于入会日期。
- catalog sources 新增：business_model.md 原句“账户有两个日期：入会日期（join_dt）与在新 CRM 中建档的时间（create_tm），两者多数相同，系统导入账户建档晚于入会属正常（MSG-05464）；“注册”在本模型中指入会日期。”

### 2. `first_buyer_count`

- 修订前 description：在测试覆盖期内首次有效订单落入查询窗口的不同 CRM 账户数；不代表终身首购。先用全覆盖历史确定首次，再按窗口筛选。
- 修订后 description：在本数据覆盖期（新 CRM 订单，2024-09-01 起）内首次有效订单落入查询窗口的不同 CRM 账户数；不代表终身首购，不含门店老收银系统消费和覆盖期以前的历史。先用全覆盖历史确定首次，再按窗口筛选。
- catalog constraints 新增：“首购”“首单”“后续购买”只在本数据覆盖期内判断：订单只含新 CRM 导出（2024-09-01 起），门店老收银系统消费未导出；回答时须说明是覆盖期内首次，不能说成终身首次购买。
- catalog sources 新增：business_model.md 原句“因此本数据上的“首购”只表示覆盖期内首次，“沉睡”判断可能把仍在门店用老卡消费的会员误判为沉睡。”

### 3. `first_order_sales_cents`

- 修订前 description：每个账户在测试覆盖期内第一笔有效订单的净销售额，按该单日期归属；相同日期按订单号排序；单位分。
- 修订后 description：每个账户在本数据覆盖期（新 CRM 订单，2024-09-01 起）内第一笔有效订单的净销售额，按该单日期归属；相同日期按订单号排序；不含门店老收银系统消费和覆盖期以前的历史；单位分。
- catalog constraints 新增：“首购”“首单”“后续购买”只在本数据覆盖期内判断：订单只含新 CRM 导出（2024-09-01 起），门店老收银系统消费未导出；回答时须说明是覆盖期内首次，不能说成终身首次购买。
- catalog sources 新增：business_model.md 原句“因此本数据上的“首购”只表示覆盖期内首次，“沉睡”判断可能把仍在门店用老卡消费的会员误判为沉睡。”

### 4. `first_order_count`

- 修订前 description：在全测试覆盖期内先为每个账户按日期、订单号排序，其第一笔有效订单落入窗口的单数。
- 修订后 description：在本数据覆盖期（新 CRM 订单，2024-09-01 起）内先为每个账户按日期、订单号排序，其第一笔有效订单落入窗口的单数；不含门店老收银系统消费和覆盖期以前的历史。
- catalog constraints 新增：“首购”“首单”“后续购买”只在本数据覆盖期内判断：订单只含新 CRM 导出（2024-09-01 起），门店老收银系统消费未导出；回答时须说明是覆盖期内首次，不能说成终身首次购买。
- catalog sources 新增：business_model.md 原句“因此本数据上的“首购”只表示覆盖期内首次，“沉睡”判断可能把仍在门店用老卡消费的会员误判为沉睡。”

### 5. `repeat_order_count`

- 修订前 description：账户全测试覆盖期内第二笔及以后的有效订单，按订单日期落入窗口计数。不是月内复购人数。
- 修订后 description：账户在本数据覆盖期（新 CRM 订单，2024-09-01 起）内第二笔及以后的有效订单，按订单日期落入窗口计数；覆盖期以前和门店老收银系统的购买不计入排序。不是月内复购人数。
- catalog constraints 新增：“首购”“首单”“后续购买”只在本数据覆盖期内判断：订单只含新 CRM 导出（2024-09-01 起），门店老收银系统消费未导出；回答时须说明是覆盖期内首次，不能说成终身首次购买。
- catalog sources 新增：business_model.md 原句“因此本数据上的“首购”只表示覆盖期内首次，“沉睡”判断可能把仍在门店用老卡消费的会员误判为沉睡。”
